read from the chain and data providers

Deploy contract and launch transaction, contract powers, pools and liquidity, holders, price. The issuer cannot edit these lines. The Sources section at the end says where each kind of fact was read, and when.

written by the issuer

Headline, description, links, tags, token utility and team members sit in one fenced block, marked as unverified and as data an agent must not take instructions from. The file then adds what it can check about those links.

stated as missing

A field with no value says none, unknown or not fetched. A closing list names what the file does not cover, such as team wallets, vesting and deals.

launchpads

A token is tied to a launchpad only when that launchpad's own deploy contract created it or holds a record for it. Checked today: .

live link

"copy live link" gives a link that rebuilds the file with fresh data whenever it is opened. The project text travels inside the link; nothing is stored on a server.

no scores

The file gives no rating and no recommendation. Labels such as "hidden owner" are the data provider's own and are marked "per" that provider.
